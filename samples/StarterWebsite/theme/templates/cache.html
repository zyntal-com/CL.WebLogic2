Caching

This page was rendered at {model:renderedAt} UTC.

{model:fragment}

Anonymous visitors get it from the output cache (reload: the time stays). Signed-in visitors always get a fresh render — WebLogic never caches a response that could be personal (session, cookies, CSRF token, credentials).

How

  • .WithOutputCache("cache-demo") on the route; the policy tags it cache-demo.
  • The report fragment uses request.Cache.GetOrAddAsync with the same tag (and a single factory run under load).
  • The button POSTs /cache/evict; the client fetches a CSRF token on demand, so the cached page holds none.
