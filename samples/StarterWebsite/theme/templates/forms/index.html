What happens here

  • CSRF field, honeypot and a signed timestamp are added automatically.
  • Rules run in the browser from the server schema, then again on the server.
  • EventSignupValidator adds a cross-field rule.
  • Uploads are sniffed by content and measured — the extension is not trusted.
  • Without JavaScript the same form posts normally and errors come back with status 422.
