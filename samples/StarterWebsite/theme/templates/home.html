A web toolkit you build on

This site is the reference app for CL.WebLogic: routing, templates, an ordered security pipeline, accounts with two-factor and API keys, forms, widgets, dashboards, realtime and caching — with persistence owned by the app (JSON files here).

Accounts

Registration, e-mail verification, password reset, TOTP two-factor with recovery codes, Steam sign-in and personal API keys.

Forms

Model-driven forms: validation on both sides, conditional fields, repeaters, uploads checked by content, a wizard, a honeypot.

Dashboard

Widgets you arrange with drag and drop or Alt+arrow keys. Layouts are saved per user with optimistic versions.

Live wall

Server-sent events with audiences and replay on reconnect. Post from the page or with an API key.

Caching

Output cache for anonymous pages (never for personal ones) and a tagged fragment cache.

Explorer

Every route with its protection, the security pipeline, widgets and forms. Open in Development; admins only in production.
